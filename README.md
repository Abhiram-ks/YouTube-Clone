YouTube Front Page Clone – HTML5 & CSS

- Project Overview:
This is my first front-end cloning project, where I recreated the YouTube homepage layout using HTML5 and CSS3. It marked the beginning of my programming journey and helped me understand the structure and styling of real-world web applications.
The clone focuses on replicating YouTube’s visual design, layout, and responsiveness, making it a great hands-on practice for front-end development and responsive design principles.

- Key Features(🚀):
* Responsive Design – Works smoothly on desktop, tablet, and mobile devices
* Structured Layout – Header, sidebar, and video grid sections
* Clean UI – Styled to closely match YouTube’s homepage
* Reusable Components – Cards for video previews and navigation
* Learning-Based – Built to strengthen HTML and CSS fundamentals

- Tools & Technologies: 
HTML5 | CSS3 | Responsive Design – Mobile-friendly layout using media queries | Version Control
